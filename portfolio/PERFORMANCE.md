## 🅲 Sleeve C｜期權疊加（33%）

同一份名單，以近價期權表達方向，指數自首次開倉起 base 100。
本倉設**建倉閘**：預期組差不足以覆蓋權利金成本時，一注不落。

| 日期 | C 指數 | 該週回報 |
|---|---|---|
| 2026-07-27 | 100.00 | 基準 |

**至今未建立過任何倉位。** 最近一次嘗試 2026-07-27（2026-07-26 名單）：建倉閘**未通過**——預期組差 8.5pp、權利金成本 0.0pp、IV 覆蓋率 0%。

逐檔不落注的原因（如實列出，不作歸納）：

| 標的 | 原因 |
|---|---|
| `NET` | 判定與自身條件紀錄矛盾，且證據重複計算；訊號 -2.5，\|訊號\| < 1.6，不落注 |
| `AMD` | 訊號 +0.9 < 1.6，不落注 |
| `ISRG` | 訊號 -0.9，\|訊號\| < 1.6，不落注 |
| `CEG` | 期權無報價 |
| `IFNNY` | 2–4 週內無到期 |
| `PLTR` | 20260821 無可成立的近價合約 |

_零倉位是本倉的正常輸出之一，不是故障：閘的存在就是為了在期權定價已經吃掉預期組差時不下注。把「未開倉」寫成 +0.0% 或者索性不提，會令讀者以為這條倉在跑而且打和。_
